# 판정 변화 해석

388건 전체의 현재 결과는 동등207·불일치76·거절43·미완료1·기존 생성 실패59·준비 오류2다.
LLM 재생성 없이 기존 후보를 사용했고, 실제 재검증은 약171초 걸렸다.

| 사례 | 변화 | 근거 |
| --- | --- | --- |
| C01_009 | 거절 → 동등 | 온도 출력의 값 흐름을 기호로 비교해 전체 값 열거를 대체 |
| C01_017 | 거절 → 동등 | 앞서 승인한 VOID 반환 대입 교정 + 문자열 기호 비교 |
| C01_018 | 거절 → 동등 | GetMenu의 None 없는 STRING 계약 + 기호 비교 |
| C21_001 | 불일치 → 동등 | BOOL을 true/false만 허용하는 합의 반영; 기존 반례는 None을 사용 |

C21_001에서 거실 입력을 L, 침실 입력을 B라고 하면 IR의 끄기 조건은
`not(L == true) or B == false`다. 생성 코드의 조건은
`not(L == true and B == true) or (L == false and B == false)`다.
BOOL만 허용하면 둘 다 `not L or not B`와 같아 네 조합에서 ACTION이 일치한다.
이전 반례는 L=true, B=None이어서 현재 모델의 입력 범위에 속하지 않는다.
정답이나 후보를 이번 실행에서 바꿔 동등 판정을 만든 것이 아니다.

기호 인증3건을 제외하고 두 유한 탐색이 모두 완료한267건에서 판정 불일치는0건이다.
exact 미완료14건 중 Explorer는12건 동등·1건 불일치를 판정했고, C01_014만 둘 다
입력 조합 상한 때문에 미완료였다. 모든 Explorer 불일치는 구체 반례 재생으로 확인됐다.

다음은 C01_014의 입력 조합 상한 처리 검토다. 그 뒤 현재 지원 범위·시간 범위와
증명 근거를 논문 설명에 연결한다. 의도적으로 거절하는 산술/D7 지원을 다시 여는
것은 이번 작업에 포함하지 않는다.

수정한 뒤 재평가했으므로 새 held-out 또는 독립 검증 결과로 부르지 않는다.
