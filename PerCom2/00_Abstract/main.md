# Abstract

Large language models (LLMs) enable users to create smart-home automation code through natural-language requests. However, implicit temporal semantics and dynamic behavior make it difficult for humans or LLM judges to assess behavioral correctness from source code alone. We present VETS, a framework for generating automation code from natural-language requests and verifying its behavior before deployment. VETS uses user-confirmed Timeline IR as a common reference for code generation and verification. Timeline IR makes event, state, and temporal relationships explicit and defines the expected timed action trace for a given device binding, initial state, and timed input sequence. Behavioral Explorer jointly explores the IR and generated code under shared inputs to check equivalence within specified input ranges and execution rules. We encoded 92 in-scope external requests in Timeline IR and reproduced their expected behavior on request-specific test inputs. In an evaluation of 200 JOI IR–code pairs, all 184 verdicts issued by Explorer agreed with independent reference checks on tested inputs or replayed counterexamples. In a scale evaluation of 30 parameterized automations, Explorer completed 28 checks, including 24 within 5 seconds, compared with 12 completed by explicit-state exploration under a 120-second budget per run.
