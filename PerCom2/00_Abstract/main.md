# Abstract

Large language models (LLMs) enable users to create smart-home automation code through natural-language requests. However, implicit temporal semantics and dynamic behavior make it difficult for humans or LLM judges to assess behavioral correctness from source code alone. We present VETS, a framework for generating automation code from natural-language requests and verifying its behavior before deployment. VETS uses user-confirmed Timeline IR to guide code generation through its control-flow structure and timing conditions, while its execution semantics provide the behavioral reference for verification. Behavioral Explorer formally verifies behavioral equivalence between the confirmed Timeline IR and generated code by jointly exploring their executions under shared inputs. On 200 JOI IR–code pairs, Explorer issued definitive verdicts for 184 pairs, all of which agreed with independent reference checks. Using input grouping and timer relations to reduce exploration, Explorer completed checks for 28 of 30 parameterized automations, including 24 within 5 seconds.
