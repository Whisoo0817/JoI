# Abstract

Large language models (LLMs) enable users to create smart-home automation code through natural-language requests. However, implicit temporal semantics and dynamic behavior make it difficult for humans or LLM judges to assess behavioral correctness from source code alone. We present VETS, a framework for generating automation code from natural-language requests and verifying its behavior before deployment. VETS uses user-confirmed Timeline IR to guide code generation through its control-flow structure and timing conditions, while its execution semantics provide the behavioral reference for verification. Behavioral Explorer formally verifies behavioral equivalence between the confirmed Timeline IR and generated code by jointly exploring their executions under shared inputs. We encoded 92 in-scope external requests in Timeline IR and reproduced their expected behavior on request-specific test inputs. In an evaluation of 200 JOI IR–code pairs, all 184 verdicts issued by Explorer agreed with independent reference checks on tested inputs or replayed counterexamples. In a scale evaluation of 30 parameterized automations, Explorer completed 28 checks, including 24 within 5 seconds, compared with 12 completed by explicit-state exploration under a 120-second budget per run.
