# 초록

대규모 언어 모델(LLM)을 통해 사용자는 자연어 요청으로 스마트홈 자동화 코드를 생성할 수 있다. 그러나 암묵적인 시간 의미와 동적인 행동 때문에 사람이나 LLM 판정기가 소스 코드만으로 행동의 정확성을 평가하기는 어렵다. 본 논문은 자연어 요청으로부터 자동화 코드를 생성하고 배포 전에 그 행동을 검증하는 프레임워크 VETS를 제안한다. VETS는 사용자가 확정한 Timeline IR을 코드 생성과 검증의 공통 기준으로 사용한다. Timeline IR은 사건·상태·시간 관계를 명시하고, 주어진 기기 바인딩과 초기 상태, 시간에 따른 입력 시퀀스에 대해 기대되는 timed action trace를 정의한다. Behavioral Explorer는 공유 입력에서 IR과 생성 코드를 함께 탐색하여 지정된 입력 범위와 실행 규칙 안에서 행동 동등성을 검사한다. 외부 요청 중 평가 범위에 해당하는 92건을 Timeline IR로 표현하고 요청별 테스트 입력에서 기대 행동을 재현했다. JOI IR–코드 200쌍에 대한 평가에서 Explorer가 내린 184개 판정 모두 테스트 입력 또는 반례 재생을 통한 독립적인 기준 실행 점검과 부합했다. 규모를 변화시킨 자동화 30개에 대한 평가에서는 회당 120초 한도에서 Explorer가 28개의 검사를 완료했으며, 이 중 24개는 5초 이내에 완료했다. 명시적 상태 탐색은 12개의 검사를 완료했다.
