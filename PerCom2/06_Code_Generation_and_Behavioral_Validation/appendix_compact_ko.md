# Explorer의 건전성: 증명 개요

6절의 바인딩, 시작 시각, 입력값 범위, 초기 상태와 실행 규칙을 \(M\)으로 고정한다. 파싱, 의미 해석과 Z3의 결과가 올바르고, 각 논리 시각에서의 실행은 유한 단계 안에 끝나며, 유한 시간 안에 실행이 무한히 재개되지 않는다고 가정한다. 실행 시간축에 상한을 두지 않고 완료한 지원 범위 내 검사를 대상으로 한다.

**주장.** 동등 판정은 \(M\)이 허용하는 모든 초기 상태와 시간 정보가 포함된 입력 시퀀스에 대해 timed action trace가 같음을 뜻한다.

**증명 개요.** 검사가 포함하는 모든 IR–코드 상태 쌍을 \(R\)로 나타내자. 여러 상태를 함께 표현했다면 개별 상태도 모두 포함한다. 검사 완료에는 다음 조건이 필요하다.

\[
  \operatorname{Init}_M\subseteq R,\qquad
  \operatorname{Post}_M(R)\subseteq R.
\]

여기서 \(\operatorname{Init}_M\)은 허용된 모든 초기 상태 쌍을, \(\operatorname{Post}_M(R)\)은 \(R\)에서 도달할 수 있는 모든 허용 후속 상태를 나타낸다. \(R\) 전체에서 명령과 발생 시각이 일치해야 한다. 종료한 프로그램은 이후 명령을 내보내지 않는다.

입력값을 묶을 때는 조건 판단과 이후 행동을 보존해야 하며, 액션 인자나 계산에 쓰이는 값은 실제 값의 차이까지 검사해야 한다. 검사 결과를 재사용할 때는 이후 행동에 영향을 주는 상태 정보를 유지해야 한다. 중간 시점을 생략할 때는 액션이나 관련 상태 변화를 놓치지 않고, 경과 시간과 재개 시 가능한 모든 입력을 보존해야 한다. 타이머 관계는 가능한 모든 분기와 후속 상태를 포함해야 한다. 표현 범위를 넓히면 기존 상태와 새 상태를 모두 포함하고 다시 검사한다~\cite{cousot1977}. 이 조건 아래에서 남은 검사 대상이 없으면, 최종 집합은 모든 후속 상태를 포함하고 전체에서 명령이 일치한다. 추가로 포함된 도달 불가능한 상태에도 같은 조건이 적용된다. 종료하는 기호 분석은 대신 가능한 모든 경로를 종료까지 검사하여 명령과 발생 시각의 일치를 확인해야 한다.

따라서 허용된 어느 초기 상태 쌍에서 시작하든 각 단계는 검사한 범위 안에 머물며 명령 일치를 유지한다. 귀납법으로 모든 유한 실행 구간에서 일치가 성립하고, 시간 진행 가정에 따라 전체 timed action trace로 확장된다. 불일치는 허용된 초기 상태부터 재생하여 차이를 확인해야 한다. 지원하지 않는 연산, 실행 오류나 예산 소진에는 동등 판정을 내리지 않는다. 이 수작업 증명 개요는 구현을 기계적으로 검증한 것은 아니다.
