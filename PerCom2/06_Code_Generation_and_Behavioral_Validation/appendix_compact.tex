\section{Explorer Soundness: Proof Sketch}
\label{app:explorer-soundness}

Fix the bindings, start time, input ranges, initial states, and execution rules of Section~VI as $M$. Assume correct parsing, interpretation, and Z3 results, finite execution at each logical time, and no infinite resumptions within finite time. Consider supported checks completed without limiting the execution timeline.

\textbf{Claim.} An equivalence verdict implies equal timed action traces for every initial state and timed input sequence allowed by $M$.

\textit{Proof sketch.} Let $R$ include all IR--code state pairs represented by the completed check. Completion requires
\[
  \operatorname{Init}_M\subseteq R,\qquad
  \operatorname{Post}_M(R)\subseteq R.
\]
Here, $\operatorname{Init}_M$ contains all allowed initial pairs, and $\operatorname{Post}_M(R)$ contains every allowed successor of $R$. Commands and times must match throughout $R$. Terminated programs issue no further commands.

Grouping inputs must preserve condition results and subsequent behavior; action arguments and computations require checking actual-value differences. Reusing checks must retain state information affecting future behavior. Skipping time points must miss no action or relevant state change, preserving elapsed time and all possible inputs at resumption. Timer relations must cover every feasible branch and successor. Enlarged ranges retain old and new states and are rechecked~\cite{cousot1977}. Finishing these checks establishes successor coverage and command agreement, including additional unreachable states. Terminating symbolic analyses instead require matching commands and times on every feasible path through termination.

From any allowed initial pair, each step stays within checked states with matching commands. Induction gives agreement for every finite execution sequence; time progress extends it to full timed action traces. Divergence requires replay from an allowed initial state to confirm a trace difference. Unsupported operations, execution errors, and exhausted budgets yield no equivalence verdict. This manual argument does not machine-verify the implementation.
