# 결론

본 논문은 자연어 요청으로부터 스마트홈 자동화 코드를 생성하고 배포 전에 그 행동을 검증하기 위해, 사용자가 확정한 Timeline IR을 코드 생성과 검증의 공통 기준으로 사용하는 VETS를 제안했다. Timeline IR은 실행 순서와 시간 조건을 명시하여 사용자 검토와 코드 생성을 지원하고, Behavioral Explorer는 IR과 코드가 동일한 입력에서 같은 액션을 같은 시각에 생성하는지 검사한다. 불일치가 발견되면 구체적인 반례를 제공하며, 검사를 완료하지 못한 코드는 검증된 것으로 승인하지 않는다.

외부에서 수집한 요청 중 평가 범위에 해당하는 92건을 Timeline IR로 표현하고 요청별 테스트에서 기대 행동을 재현했다. 판정 신뢰성 평가에서는 Explorer가 내린 184개 판정 모두 독립적인 기준 실행 점검과 부합했다. 비용 평가에서는 30개 프로그램 중 28개를 120초 한도 안에서 검사했다. 이 결과는 자연어 의도의 올바른 해석을 전제로, 확정된 명세와 생성 코드 사이의 행동 차이를 배포 전에 확인하는 접근의 가능성을 보여준다.
