# Abstract — PerCom working draft

While Large Language Models (LLMs) can translate natural-language requests into smart-home automation rules, implicit temporal semantics and dynamic behaviors make source-code-based verification unreliable. Existing approaches rely heavily on manual inspection or secondary LLM checks rather than systematic behavioral verification. We present VETS, a framework that translates natural-language requests into executable behavioral specifications and formally verifies generated code against them. At its core is Timeline IR, an intermediate representation that explicitly formalizes implicit event, state, and temporal relationships. Once user-confirmed, Timeline IR serves as the executable ground truth. VETS then leverages a Behavioral Explorer to check whether the generated code matches the IR's execution trace. By exploring behavior-changing input and time boundaries and merging states under future-preserving relations, Behavioral Explorer checks reachable IR-code product states without imposing a fixed time-step horizon. It certifies equivalence only after the applicable exploration reaches closure, reports a replayable witness when the traces diverge, and otherwise returns a non-certifying outcome. **[Final experimental results will be inserted after the current E1–E4 protocols and audits are complete.]**
