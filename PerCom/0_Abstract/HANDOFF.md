# Abstract handoff

상태: **교수님 제공 working draft + 현재 검증 계약 반영**.

- SenSys의 382개·99.3%·repair·physical deployment·0.97 ms 수치는 자동 이관하지 않는다.
- 교수님이 제공한 문장을 기준본으로 유지한다. 방법·보장 범위가 바뀌거나 구체적인 최종 실험 결과가 나오면 그 부분만 갱신한다.
- 구 fixed-horizon 결과는 현 논문 설정에서 폐기했다. Abstract와 PerCom 본문에서 해당 실험의 pair 수·transition 감소율·latency 수치를 제거했다.
- 최종 초록은 E1–E4가 끝난 뒤 결과 문장을 채우고 전체 정합성만 다시 점검한다.
- `VETS`는 작업명이다. 제목 결정 후 전체 원고와 함께 치환한다.
- 현재 방법 문장은 H=None에서 해당 탐색 경로가 closure/completion 조건을 만족할 때만 EQUIV를 인증한다는 검증 계약을 따른다.
- E1/E2/E4가 미완료인 동안 “전체 검증기 정확도”, “Timeline coverage”, “unbounded verifier 성능 우위”를 주장하지 않는다.
