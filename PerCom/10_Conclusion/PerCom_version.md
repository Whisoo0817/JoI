# Conclusion

We presented VETS, which checks whether generated smart-home code preserves behavior specified in a confirmed Timeline IR. Behavioral Explorer compares the IR and code under shared inputs, checking both actions and their timing. It certifies equivalence only when its completion conditions hold under the declared execution model, and provides a counterexample when behaviors differ. Unsupported or unfinished checks remain undecided. Among 382 generated JoI candidates, Explorer identified 68 behavioral mismatches, all confirmed by its concrete replay. VETS thus makes the confirmed behavior an executable reference for checking generated implementations and exposes differences that users would otherwise need to find in the code.
