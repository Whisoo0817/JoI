# 결론

우리는 생성된 스마트홈 코드가 확정된 Timeline IR에 명시된 동작을 보존하는지 검사하는 VETS를 제시했다. Behavioral Explorer는 공통 입력 아래 IR과 코드를 비교하며 행동과 발생 시각을 함께 확인한다. 선언된 실행 모델 안에서 검사 완료 조건을 충족한 경우에만 동등성을 보장하고, 동작이 다르면 반례를 제공한다. 지원하지 않거나 완료하지 못한 검사는 미확정으로 남긴다. 생성된 JoI 코드 후보 382개에서 Explorer는 행동 불일치 68개를 찾았고, 모두 구체 실행으로 확인했다. 이처럼 VETS는 확정된 동작을 생성 코드의 실행 가능한 검사 기준으로 삼아, 사용자가 코드에서 직접 찾아야 할 행동 차이를 드러낸다.
