# Related Work — SenSys version

The SenSys manuscript organized prior work around whether a verification reference already existed. It covered formal verification of hand-authored trigger-action programs, executable tests and denotations for generated code, LLM-generated reactive automations, user-facing authoring systems, on-device language models, and LLM judges. It argued that OVLA filled a missing deterministic intent-conformance gate.

The section used several broad contrasts, including fixed negative properties versus user intent, primitive TAP rules versus code idioms, and cloud LLM judging versus local deterministic verification. Later literature review found that these contrasts require narrower wording because prior work also supports timing, liveness, user-defined properties, formal semantics, and code-derived models.
