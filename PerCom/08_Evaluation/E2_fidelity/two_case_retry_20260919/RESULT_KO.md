# E2 지원 거절 2쌍의 추가 반례 점검

원본 코드, IR, 카탈로그 및 기존 200쌍 결과는 변경하지 않았다. 입력 범위를 임의의 물리적 측정 범위로 주장하지 않고, 기존 카탈로그가 허용하는 구체적인 값으로 반례를 찾았다. 이 추가 점검은 원래 실험과 구분한다.

- C01_006/llm: 현재 채널 1에서 IR은 ChannelDown, JOI는 SetChannel(0)을 출력했다. 명시적 입력 도메인 {1}, 1초 탐색 구간에서 기존 Explorer timed_product가 DIVERGE를 반환했고, 독립 기준 실행기가 같은 반례의 차이를 확인했다. 채널 0에서 인자 -1이 되는 문제를 해결하거나 전체 도메인을 지원하게 된 것은 아니다. 판정은 기기 명령의 timed action trace 기준이며, 두 명령의 실제 기기 상태 효과가 다르다는 주장이 아니다.
- E1-095/ext60-fault2: pH 7.0, 염소 농도 2.0을 일정하게 제공했다. 명시적 도메인으로 timed_product를 호출해도 누적 변수의 유한성 검사에서 REFUSED였다. 별도 구체 실행에서 원래 100ms 입력 격자로 내부 인터프리터를 실행한 결과, 15시 보고 시점에 IR은 평균 (7.0, 2.0), JOI는 (3.5, 1.0)을 출력했다. 변형 코드가 측정 횟수를 매번 2씩 증가시키기 때문이다. 독립 기준 실행기도 같은 차이를 확인했다. 이는 재생으로 확인한 반례이며, Explorer의 자동 탐색 완료로 집계하지 않는다.

근거: results.jsonl, pool_concrete_witness.json. 실행 코드: run.py, pool_witness.py. 기존 판정 분포와 논문 수치는 갱신하지 않았다.
