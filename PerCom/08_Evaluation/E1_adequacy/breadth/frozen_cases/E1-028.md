# E1-028 — rolling-window feeder limit

Source: AutoTap User Study 1, participant P24, statement S2.

## Frozen interpretation

“Every 4 hours” denotes a rolling four-hour window. A dispense request succeeds only when fewer than two bowls were dispensed during the preceding four hours. An over-limit request emits no dispense action and no notification.

## Binding plan

- Input: `DispenseRequested`.
- Action: `Feeder.Dispense(one_bowl)`.

## Reference history and expected trace

| Time | Input | Expected action |
|---|---|---|
| t+0 min | dispense request | `Feeder.Dispense(one_bowl)` |
| t+60 min | dispense request | `Feeder.Dispense(one_bowl)` |
| t+120 min | dispense request | -- |
| t+240 min | dispense request | `Feeder.Dispense(one_bowl)` |

For a request at time `t`, count prior dispenses in `(t−4 hours, t)`. Therefore, at exactly t+240 min, the first dispense has expired.
