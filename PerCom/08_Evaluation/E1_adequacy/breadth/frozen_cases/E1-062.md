# E1-062 — bidirectional light synchronization

Source: Google Home official scripted-automation example, “Synchronize two lights.”

## Frozen interpretation

Each state change of light A is copied to light B only when B differs; each state change of B is copied to light A only when A differs. The guard prevents feedback-loop actions after a synchronized command.

## Binding plan

- Inputs: externally caused state changes of `LightA` and `LightB`.
- Actions: `LightA.On`, `LightA.Off`, `LightB.On`, `LightB.Off`.

## Reference history and expected trace

Initial state: `LightA=off`, `LightB=off`.

| Time | Input / resulting state event | Expected action |
|---|---|---|
| t+0 | external `LightA` becomes on | `LightB.On` |
| t+0+ | resulting `LightB=on` event | -- |
| t+1 min | external `LightB` becomes off | `LightA.Off` |
| t+1 min+ | resulting `LightA=off` event | -- |
