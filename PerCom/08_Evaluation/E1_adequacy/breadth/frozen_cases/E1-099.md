# E1-099 — manual light with motion extension

Source: Home Assistant Community thread 729908, “Need help with light automation.”

## Frozen interpretation

A manual switch-on creates a five-minute off deadline. Every motion event while the light is on adds two minutes to the current deadline. At the deadline, turn the light off only when there has been no motion during the preceding two minutes. Motion extends the existing deadline; it does not restart a timer from the motion event.

## Binding plan

- Inputs: `ManualLightOn` and `MotionDetected`.
- Action: `Light.Off(hall)`.

## Reference history and expected trace

| Time | Input | Expected action |
|---|---|---|
| t+0 min | manual switch turns hall light on | -- |
| t+1 min | motion detected | --; deadline becomes t+7 min |
| t+4 min | motion detected | --; deadline becomes t+9 min |
| t+9 min | no motion since t+4 min | `Light.Off(hall)` |
