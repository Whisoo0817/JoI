# E1-086 — cancelable sequential sprinklers

Source: Home Assistant Community thread 878961, “Stop an automation mid-run via an input boolean?”

## Frozen interpretation

Turning the control input on starts zone 1 for ten minutes, followed by a 30-second gap and zone 2 for ten minutes. Turning the input off at any point immediately turns off both zones and cancels all remaining waits/actions. Home Assistant restart behavior is excluded.

## Binding plan

- Input: `SprinklerRun` boolean.
- Actions: `Valve.On(zone1)`, `Valve.On(zone2)`, `Valve.Off(zone1)`, `Valve.Off(zone2)`.

## Reference history and expected trace

| Time | Input | Expected action |
|---|---|---|
| t+0 min | `SprinklerRun = on` | `Valve.On(zone1)` |
| t+5 min | `SprinklerRun = off` | `Valve.Off(zone1)`; `Valve.Off(zone2)` |
| t+10 min | no input | -- |
| t+10 min 30 s | no input | -- |

The second zone must never turn on after cancellation.
