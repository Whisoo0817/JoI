# E2 원고 작성 계획 (2026-09-14, 결정 4개 whisoo 확정 — 원고 파일은 아직 쓰지 않음)

근거 수치는 `E2_SUMMARY.md` §4 와 `RESULTS.md` "Final version" 절. 원고(`PerCom/6_Evaluation/PerCom_version.md`)는 whisoo 가
핵심 문장 표현을 확인한 뒤 쓴다.

## 1. 논문 안에서의 위치

- **Evaluation 의 두 번째 실험.** E1(요구 표현 적합성)이 "Timeline 으로 적을 수 있는가" 였다면, E2 는 **"Explorer 가 두 프로그램의
  같음/다름을 정확히 판정하는가"** 이다. E2 의 목적은 Explorer 의 능력(정확도)을 보여 주는 것.
- **뒤 실험의 전제.** E3(생성 결과 평가)는 Explorer 판정을 그대로 결과로 쓴다.
- **분량**: 약 0.6 쪽 (방법 한 문단, 표 1개, 결과 두 문단, 한계 반 줄).

## 2. 핵심 문장 (확정 후보)

> Explorer 가 판정한 131쌍 중 독립 정답기와 어긋난 판정은 없었다(130쌍 확인, 1쌍은 정답기가 JoI 를 실행할 수 없음).
> LLM 생성 후보 39개는 전부 판정했고, 직접 만든 경계 요구 20개 중 18개를 판정했다.
> 남은 2개는 상태 폭발과 동작 횟수에 따른 시한이라는 두 유형이다.

영문 초안(확정 전):
> *None of the 131 verdicts the Explorer issued was contradicted by the independent reference (130 confirmed; for one,
> the reference cannot execute the generated JoI). The Explorer decided all 39 valid LLM-generated candidates and
> 18 of the 20 hand-built boundary requirements; the two remaining requirements fall into two classes: state
> explosion from nested repetition and timers, and deadlines that grow with the number of actions.*

## 4. 절 구성

1. **질문과 방법 (한 문단)**
   - 독립 정답기: 명세만 보고 별도 작성자가 만든 IR·JoI 실행기. E1 기대 결과와 일치(41/41, 12/12, 15/15).
   - 쌍: E1 요구 20개의 올바른 쌍 21 + 오류 쌍 81, 388 데이터셋 무작위 LLM 후보 40.
   - 비교: 정답기 입력 이력에서의 차이, Explorer 반례의 정답기 재생.
   - 거절·시간 초과는 분모에 남긴다.
   - 바인딩: 따로 설명하지 않는다. 필요하면 "기기 선택은 비교 대상이 아니다(§3)" 수준의 한 구절만.
2. **표 (Table E2, 하나)**
   - 윗부분 "Fidelity": 판정 131 / 정답기 확인 130 / 확인 불가 1 / 어긋남 0 / 실제 차이가 있는 오류 75 중 DIVERGE 69, 놓침 0, 미결정 6.
   - 아랫부분 "Coverage": LLM 39/39, 직접 만든 요구 18/20(쌍 92/102), 미결정 원인 2유형(각 5쌍) + 입력 오류 1.
   - 바인딩으로만 달라지는 오류 쌍 3개(C16/f1, E1-062/f3, E1-086/f3)는 두 도구 모두 EQUIV 라 "실제 차이가 있는 오류 75" 에
     원래 들어가지 않는다. 표 각주 없이 둔다. 오류 쌍 수를 적어야 할 때는 81 을 그대로 쓰고 "관찰 가능한 차이" 기준 75 로 설명.
3. **결과 문단 1 — 신뢰성**: 핵심 문장 1. 반례로만 확인된 쌍은 정답기 이력이 닿지 못한 입력임을 한 문장으로.
4. **결과 문단 2 — 판정 범위**: 핵심 문장 2·3. 두 유형을 C07·E1-099 예로 짧게. C20_011 은 입력 검증 단계에서 거절된 LLM 오류로 분리.
5. **한계**
   - E2 안(반 줄): 정답기의 "같음" 은 입력 이력 범위 안의 증거다.
   - Limitations 절로: 정답기와 Explorer 는 같은 명세를 따른다(코드 수준 독립), 오류 쌍은 요구별로 묶여 독립 표본이 아니고 LLM 표본은 40.

## 5. 쓰지 않을 것

- "정확도 100%", "동등성을 증명", "명세가 옳음을 확인".
- 92%(131/142)를 정확도로 부르기. 판정 비율과 판정 신뢰성을 섞지 않는다.
- C07·E1-099 를 분모에서 빼기, LLM 39/39 를 388 전체로 일반화하기.
- 동결판·중간판 수치, 같은 쌍을 보고 개선했다는 경과 (결정 2).
- all/any, 셀렉터 나열, 바인딩 여러 개일 때의 비교 규칙, "범위 밖" 이라는 표현 (결정 3).
