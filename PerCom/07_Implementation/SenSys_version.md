# Implementation — SenSys version

The SenSys prototype was implemented in approximately 4,850 lines of Python. It used llama.cpp-compatible local inference for generation, JSON-schema and catalog checks for Timeline IR, a deterministic renderer, an IR simulator, a JoI simulator, and a verifier connected to a commercial home-automation hub. The section emphasized a Mac mini M4 deployment and no LLM call in the final gate.
