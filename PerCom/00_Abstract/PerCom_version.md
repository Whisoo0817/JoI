## Version 1 — 교수님 확인 버전 (약 1주일 전)

> 비교용 원문 보존. 아래 실험 수치는 당시 버전의 결과이며 현재 PerCom의 최종 실험 결과가 아니다.

While Large Language Models (LLMs) can translate natural-language requests into smart-home automation rules, implicit temporal semantics and dynamic behaviors make source-code-based verification unreliable. Existing approaches rely heavily on manual inspection or secondary LLM checks rather than systematic behavioral verification. We present VETS, a framework that translates natural-language requests into executable behavioral specifications and formally verifies generated code against them. At its core is Timeline IR, an intermediate representation that explicitly formalizes implicit event, state, and temporal relationships. Once user-confirmed, Timeline IR serves as the executable ground truth. VETS then leverages a Behavioral Explorer to check whether the generated code matches the IR's execution trace. By analyzing only critical temporal boundaries and input values that influence trace changes, Behavioral Explorer significantly reduces state exploration overhead. In an evaluation of 311 IR-code pairs across 32 discrete time steps, Behavioral Explorer achieved zero false accepts and zero false rejects, matching exhaustive verification verdicts perfectly. Furthermore, it reduced state-transition evaluations by 73.4% compared to exhaustive search, achieving a p95 analysis time of just 52.1 ms.

## Version 2 — 사용자 수정 버전 (최근 1주일 결과 일부 반영)

Large language models (LLMs) are being used to generate automation code, enabling users to create smart-home automations through natural-language requests. LLM-generated automation code is often checked by humans or other LLMs, but implicit temporal semantics and dynamic behaviors make its behavioral correctness difficult to assess from source code alone. We present VETS, a framework that translates natural-language requests into executable behavioral specifications and formally verifies whether the code generated from them preserves the specified behavior. At its core is Timeline IR, an intermediate representation that explicitly formalizes implicit event, state, and temporal relationships. Once confirmed by the user, Timeline IR defines the expected timed action trace for a given binding, initial state, and timed input trace. Behavioral Explorer jointly explores Timeline IR and the generated code under shared timed input traces, comparing their observable actions and timing. In an evaluation of 140 JoI IR–code pairs, Behavioral Explorer reached verdicts for 130 pairs, with none contradicted by an independently implemented reference interpreter. In a separate scale evaluation on 30 parameterized automations, Behavioral Explorer decided 28, 19 of them in under a second, whereas explicit-state exploration decided 12.
