# VESTA English Abstract

Large language models (LLMs) can translate natural-language requests into executable smart-home automation rules. However, these requests often leave event, state, and temporal relationships implicit, so they do not provide an executable reference for checking the generated code. Automation behavior also unfolds over time through triggers, durations, and repeated executions, making correctness difficult to judge from source code alone. Existing validation methods rely on manual code inspection or LLM-based re-checking rather than systematic comparison of execution behavior.

We present VESTA, a framework that turns natural-language automation requests into executable behavioral specifications and verifies LLM-generated code against them. VESTA places a user-confirmed intermediate specification, Timeline IR, between the request and generated code. Timeline IR expresses implicit event, state, and temporal semantics as behavioral operators and produces a unique action trace for a given initial state and timed input sequence. Once confirmed, the IR becomes the executable reference that generated code must follow. An LLM then translates the IR into automation code for the target platform.

Within a finite input model and bounded execution length, VESTA's Behavioral Explorer checks whether generated code implements the confirmed IR. Rather than examine every time point, it explores only input values and temporal boundaries that can change the action trace. It then executes the IR and code on synthesized input sequences and compares their action traces. We evaluated 311 IR-code pairs over executions bounded to 32 discrete time steps. Exhaustive enumeration found 231 matching programs and 80 mismatching programs. Behavioral Explorer agreed with these verdicts for all 311 pairs: no mismatching program was accepted, and no matching program was rejected. On the 231 matching pairs, it reduced state-transition evaluations by 73.4% compared with exhaustive enumeration, with a p95 analysis time of 52.1 ms.
