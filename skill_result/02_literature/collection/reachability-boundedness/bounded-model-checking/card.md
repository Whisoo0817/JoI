# TL;DR

Bounded model checking formalizes the value and limitation of searching executions only up to an explicit bound.

## Relevance to new OVLA

It supports precise language such as “exhaustive within the declared finite model and bounds,” plus explicit reporting of horizon exhaustion and incomplete searches.

## Boundary

A finite search result is not an unbounded program-equivalence theorem. New OVLA's contribution is its reference/adapter/observation integration, not bounded search itself.
