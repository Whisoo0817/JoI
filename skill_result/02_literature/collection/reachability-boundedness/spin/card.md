# TL;DR

SPIN is a canonical explicit-state model-checking reference for enumerating reachable states and producing error traces.

## Relevance to new OVLA

It supports disciplined Explorer terminology: canonical state, successor relation, visited-state deduplication, frontier, resource limits, and reproducible counterexamples.

## Boundary

New OVLA should not claim reachability exploration itself as novel, and should not imply unbounded completeness.
