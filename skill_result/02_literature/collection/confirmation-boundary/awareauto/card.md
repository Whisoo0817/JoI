# TL;DR

AwareAuto uses LLMs and structured interaction to express complex smart-home automations, including temporal constraints, while keeping users in the loop.

## Relevance to new OVLA

It is the closest source for motivating a user-facing confirmation boundary. It also prevents an overclaim: interactive clarification or confirmation is not itself new.

## Boundary

AwareAuto evaluates intention matching, feasibility, controllability, and usability. New OVLA deliberately begins after Timeline IR confirmation and does not claim that confirmation establishes true user intent.
