# New OVLA–PerCom alignment

## Alignment statement

New OVLA aligns with PerCom 2027 as a smart-home/pervasive systems and methodology contribution: it turns confirmed reactive-temporal automations into an executable reference and verifies generated implementations under modeled pervasive events. The formal machinery serves a pervasive systems problem.

## Strong alignment points

- Smart homes, pervasive virtual assistants, IoT, AI, cyber-physical systems, programming paradigms, and spatio-temporal modeling all appear in the official scope.
- The planned interpreter–Explorer–adapter–comparator is a concrete systems artifact.
- E1–E4 collectively address rigorous validation: semantics conformance, representational scope, behavioral discrimination, and capacity/resource frontier.
- Bounded and unsupported outcomes can be reported explicitly, matching the sample's emphasis on honest system limits.

## Risks and containment

| PerCom-facing risk | Containment without changing the approved flow |
| --- | --- |
| Reads as a generic formal-method paper | Every formal construct is justified by a real reactive-temporal IoT idiom; E2 contains external automation cases; E4 includes a representative pervasive workload anchor. |
| Evaluation appears immature | Freeze E1–E4 before runs; define independent oracles, controls, strata, repeated measurements, CIs, timeouts, and decision gates now. |
| “Equivalence” sounds unbounded | Repeat the exact guarantee: all reachable histories within a declared finite model and bounds. |
| Confirmation is mistaken for intent validation | State that the user-approved IR defines the verification contract; intent correctness and usability are outside scope. |
| Old OVLA numbers are mistaken for new evidence | Present them only as predecessor motivation and candidate corpus provenance; no C1–C5 support until new runs exist. |
| Artifact assumptions outrun official guidance | Keep manifests, seeds, configs, schema, outcome logs, and replay commands ready; wait for the 2027 artifact call before claiming compliance. |
