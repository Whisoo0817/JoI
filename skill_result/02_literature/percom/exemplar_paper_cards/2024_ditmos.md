# DiTMoS (PerCom 2024)

- **Focus:** distributed tiny-model selection for constrained pervasive devices.
- **Artifact/evidence:** three datasets, four baselines, repeated random initializations, ablation, and direct MCU measurements.
- **Metrics:** memory, flash, latency, and energy; latency measured over 1,000 runs.
- **Transfer to OVLA:** if the checker is positioned for edge use, measure on the actual target class with repetitions; keep this inside scalability, not as a separate contribution.
- **Source:** https://arxiv.org/abs/2403.09035
