# EcoVis (PerCom 2025)

- **Focus:** energy/connectivity-aware visual surveillance.
- **Artifact/evidence:** real outdoor testbed, benchmark plus collected data, and several competing baselines.
- **Metrics:** energy, network behavior, and task performance reveal system trade-offs.
- **Transfer to OVLA:** evaluate correctness together with time and memory cost; use a real pervasive workload anchor rather than synthetic scaling alone.
- **Source:** https://lenka98.github.io/papers/ecovis/ecovis.pdf
